# Career Goals

## Goal

To build a career in cybersecurity and use my IT and quality assurance background to support organizations in protecting people, data, and systems.

## Objectives

- Develop practical cybersecurity knowledge and technical skills
- Learn to identify vulnerabilities and assess security risks
- Support secure product development and compliance-focused practices
- Contribute to protecting customer, employee, and organizational data
- Help organizations improve security awareness and risk management

## Focus Areas

- Data protection and PII security
- Risk identification and vulnerability analysis
- Secure software and system quality
- Team collaboration and mentoring
- Security support for financial and regulated environments

## Long-Term Vision

I want to grow into a cybersecurity role where I can combine technical understanding, quality mindset, and service-driven values to help organizations strengthen their defenses and protect sensitive information.
